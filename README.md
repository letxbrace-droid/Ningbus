# ningbus

Ce dépôt contient :

- **`radar-decode/`** — Radar Décodé : veille automatique de l'actu (RSS multi-médias + alerte Telegram). Voir `radar-decode/README.md`.
- **`docs/`** — une PWA de suivi de défauts bus (RATP), déployée via GitHub Pages, indépendante de Radar Décodé.
- **`docs/masse/`** — **I&N RUN Masse**, PWA de suivi d'entraînement (prise de masse sur machines) : installable, fonctionne hors ligne. Voir `docs/masse/LISEZMOI.md`.

Le projet TrendTrack (scraper Meta Ads) qui occupait précédemment ce dépôt a été retiré.
